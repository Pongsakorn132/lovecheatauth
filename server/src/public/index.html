Application Settings & Seller API

จัดการการตั้งค่าเวอร์ชัน, Application Secret Key และ Seller API สำหรับบอทหรือร้านค้า

Version Control & Auto-Update

ควบคุมเวอร์ชันของแอปพลิเคชันและลิงก์สำหรับดาวน์โหลดตัวอัปเดต

หาก Client ใช้เวอร์ชันเก่า เซิร์ฟเวอร์จะปฏิเสธการเชื่อมต่อและส่งลิงก์นี้ไปให้เปิดดาวน์โหลด

Maintenance Mode

โหมดปิดปรับปรุงชั่วคราวเพื่อความปลอดภัย

เมื่อเปิดโหมดนี้ ไคลเอนต์ทั่วไปจะไม่สามารถ Init เข้าระบบได้ (ป้องกันคนเข้าเกมขณะเกมอัปเดต)

Hardware Lock (HWID Lock)

ผูกสิทธิ์บัญชีกับเครื่องคอมพิวเตอร์เครื่องแรก

เมื่อเปิดใช้งาน ระบบจะตรวจสอบ HWID ประจำเครื่องทุกครั้งที่มีการ Login หากนำคีย์หรือไอดีไปเปิดบนเครื่องอื่นจะถูกบล็อกทันที

Application Secret

คีย์ลับสำหรับเข้ารหัสความปลอดภัย AES-256 ระหว่าง Client และ Server

⚠️ คำเตือน: หากรีเฟรช Secret ไคลเอนต์เวอร์ชันเดิมที่ฝัง Secret เดิมจะต้องนำ Secret ใหม่ไปอัปเดต

Seller API Key

API Key สำหรับตัวแทนจำหน่าย บอท Discord หรือระบบเว็บไซต์ร้านค้าภายนอก สามารถจัดการคีย์และยูสเซอร์ได้เสมือน Admin ทุกฟังก์ชันเฉพาะแอพนี้
