5-Minute Quickstart Integration

เพิ่มการป้องกัน KawaiiAuth ลงในโค้ด C++ ของคุณด้วยการก็อปปี้ไฟล์ SDK และเขียนโค้ดเพียง 3 บรรทัด:

Step 1: เพิ่มไฟล์ในโปรเจกต์ Visual Studio MSVC x64

ก็อปปี้โฟลเดอร์ client_sdk/dist/include/KawaiiAuth.h และไฟล์ client_sdk/dist/lib/KawaiiAuth.lib ไปไว้ในโฟลเดอร์โปรเจกต์ของคุณ

Step 2: เขียนโค้ดตรวจสอบ License Key ใน main() 
#include <iostream>
#include "KawaiiAuth.h"

int main() {
    // 1. เริ่มต้นเชื่อมต่อเซิร์ฟเวอร์ด้วย App ID และ App Secret
    if (!KawaiiAuth::Init("kawaii_demo_app", "demo_app_secret", "1.0", "http://127.0.0.1:8080")) {
        std::cout << "[-] Init failed: " << KawaiiAuth::GetLastError() << std::endl;
        return 1;
    }

    // 2. รับคีย์จากผู้ใช้แล้วส่งตรวจสอบ
    std::string licenseKey;
    std::cout << "[*] Enter License Key: ";
    std::cin >> licenseKey;

    auto auth = KawaiiAuth::LicenseLogin(licenseKey);
    if (!auth) {
        std::cout << "[-] Login Failed: " << auth.message << std::endl;
        return 1;
    }

    // 3. ผ่านแล้ว! เข้าถึงโปรแกรมหลัก
    std::cout << "[+] Welcome! Time Left: " << KawaiiAuth::GetFormattedTimeLeft() << std::endl;
    return 0;
}

Zero External DLLs — 100% Native Windows

KawaiiAuth ไม่พึ่งพา OpenSSL, ไม่ต้องติดตั้ง libcurl.dll หรือใช้แพ็คเกจ vcpkg ใดๆ ทั้งสิ้น ทุกฟังก์ชันทำงานผ่าน System Libraries ที่ติดมากับ Windows ทุกเครื่อง:

Library DLL ใน Windows หน้าที่ใน SDK Auto-Linked?
wininet.lib wininet.dll HTTP/HTTPS Network Transport, SSL Verification Bypass Yes (#pragma comment)
bcrypt.lib bcrypt.dll Windows CNG (AES-256-GCM, SHA-256, Secure RNG) Yes (#pragma comment)
crypt32.lib crypt32.dll Base64 Encoder/Decoder, RSA-2048 Server Signature Validation Yes (#pragma comment)
user32.lib user32.dll Window Title & Class Detection สำหรับ Security Watchdog Yes (#pragma comment)

SDK: Initialization & Setup

bool KawaiiAuth::Init(
    const std::string& app_id,       // App ID จากแดชบอร์ด (เช่น "cs2_cheat")
    const std::string& app_secret,   // Application Secret (AES-256 Key)
    const std::string& version = "1.0", // เวอร์ชันของไคลเอนต์
    const std::string& api = "http://127.0.0.1:8080", // URL ของเซิร์ฟเวอร์
    bool enforce_integrity = false    // ตรวจสอบ Hash ดิจิทัลของตัวรันไทม์
);
พารามิเตอร์:
  • app_id: รหัสประจำตัวแอปที่ได้จากการสร้างใน Dashboard เช่น kawaii_demo_app
  • app_secret: คีย์ลับ AES-256 ดูได้ที่หน้า App Settings ของแอปนั้นๆ
  • version: หากเซิร์ฟเวอร์ตั้งค่า Required Version สูงกว่าที่ระบุ เซิร์ฟเวอร์จะปฏิเสธการเชื่อมต่อและส่งลิงก์ Download Update กลับมาให้อัตโนมัติ

SDK: Authentication Methods

1. LicenseLogin (คีย์ล้วน ไม่ต้องสมัครสมาชิก) Recommended

เหมาะสำหรับโปรแกรมโกงเกม หรือ Loader ขายคีย์วัน/สัปดาห์/เดือน ผู้ใช้กรอกเฉพาะคีย์ License ระบบจะผูก HWID อัตโนมัติในครั้งแรกที่เปิดใช้งาน 

auto result = KawaiiAuth::LicenseLogin("KAWAII-XXXX-XXXX");
if (result) {
    std::cout << "Time left: " << KawaiiAuth::GetFormattedTimeLeft() << std::endl;
} else {
    std::cout << "Error: " << result.message << std::endl;
}
2. User Login & Register (ระบบสมาชิก)

เหมาะสำหรับแอปพลิเคชันที่ต้องการให้ผู้ใช้มี Username/Password บัญชีส่วนตัว โดยใช้ License Key ในการ Redeem ขยายเวลา 

// สมัครสมาชิกครั้งแรกด้วย License Key
auto reg = KawaiiAuth::Register("user123", "password123", "KAWAII-KEY-HERE");

// ล็อกอินครั้งถัดไป
auto login = KawaiiAuth::Login("user123", "password123");

Server Variables: ดึงค่าตัวแปรแบบเข้ารหัสจากเซิร์ฟเวอร์

ฟังก์ชัน GetVariable() อนุญาตให้ผู้พัฒนาดึงค่าข้อความ, Secret Key, Token, หรือ Config ที่ตั้งไว้ในแดชบอร์ดแท็บ Server Variables โดยส่งผ่านการเข้ารหัส AES-256 ปลอดภัย: 

// ดึงค่าตัวแปรจากเซิร์ฟเวอร์ด้วย Variable Key
std::string apiKey = KawaiiAuth::GetVariable("API_KEY");
std::string configData = KawaiiAuth::GetVariable("APP_CONFIG");

if (apiKey.empty()) {
    std::cout << "[-] Variable not found or access denied." << std::endl;
} else {
    std::cout << "[+] Variable loaded: " << apiKey << std::endl;
}
💡 ประโยชน์: หากต้องการเปลี่ยนค่า Config หรือคีย์ลับ สามารถเข้าไปแก้ไขในหน้าแดชบอร์ดได้ทันที โดยไม่ต้องแจกไฟล์ .exe หรือ compile ตัวโปรแกรมใหม่

Files & Payloads: ดาวน์โหลดไฟล์ปลอดภัยสู่ RAM

ฟังก์ชัน DownloadFile() ดาวน์โหลดไฟล์หรือโมดูลไบนารีจากแท็บ Files & Payloads ลงสู่ Memory (RAM) โดยตรง ป้องกัน Antivirus จากการสแกนไฟล์บน Harddisk: 

// ดาวน์โหลดไฟล์จากเซิร์ฟเวอร์เข้าสู่หน่วยความจำ (RAM)
std::vector<uint8_t> fileBytes = KawaiiAuth::DownloadFile("core_module.dll");

if (fileBytes.empty()) {
    std::cout << "[-] Failed to download payload: " << KawaiiAuth::GetLastError() << std::endl;
    return 1;
}

std::cout << "[+] Payload loaded into RAM! Size: " << fileBytes.size() << " bytes." << std::endl;

Full Example: C++ Production Key Loader

#include <iostream>
#include <string>
#include <windows.h>
#include "KawaiiAuth.h"

int main() {
    SetConsoleTitleA("KawaiiAuth Secure Client v1.0");

    // 1. ดำเนินการ Security Watchdog เบื้องต้น
    if (!KawaiiAuth::RunSecurityChecks()) {
        std::cout << "[-] Security Violation: Analysis or debugger tool detected." << std::endl;
        Sleep(2000);
        return 1;
    }

    // 2. เริ่มต้นเชื่อมต่อเซิร์ฟเวอร์
    std::cout << "[*] Initializing cryptographic session..." << std::endl;
    if (!KawaiiAuth::Init("kawaii_demo_app", "demo_app_secret", "1.0", "http://127.0.0.1:8080")) {
        std::cout << "[-] Connection failed: " << KawaiiAuth::GetLastError() << std::endl;
        system("pause");
        return 1;
    }

    // 3. กรอก License Key
    std::string key;
    std::cout << "[*] Enter your License Key: ";
    std::cin >> key;

    auto auth = KawaiiAuth::LicenseLogin(key);
    if (!auth) {
        std::cout << "\n[-] Authentication Failed: " << auth.message << std::endl;
        system("pause");
        return 1;
    }

    // 4. แสดงผลข้อมูลสิทธิ์
    std::cout << "\n==========================================" << std::endl;
    std::cout << "[+] Authentication Successful!" << std::endl;
    std::cout << "[+] User / ID:   " << auth.user.username << std::endl;
    std::cout << "[+] Time Left:   " << KawaiiAuth::GetFormattedTimeLeft() << std::endl;
    std::cout << "[+] HWID Locked: " << KawaiiAuth::GetHWID().substr(0, 16) << "..." << std::endl;
    std::cout << "==========================================\n" << std::endl;

    // 5. ดึงตัวแปรเซิร์ฟเวอร์ (Server Variable)
    std::string configVar = KawaiiAuth::GetVariable("SERVER_CONFIG");
    std::cout << "[+] Server Variable loaded: " << configVar << std::endl;

    system("pause");
    return 0;
}

REST API Protocol (Non-C++ Integration)

สำหรับภาษาอื่นๆ เช่น Python, C#, Rust หรือ Web Application ทุก Request ผ่านการเข้ารหัสแบบ End-to-End Handshake ด้วยลำดับดังนี้:

1. POST /api/v1/init เริ่มต้น Handshake แลกเปลี่ยน Public Key และรับ Session Token + AES-256 Key
Payload: {"app_id": "kawaii_demo_app", "version": "1.0", "client_pub": "..."}
2. POST /api/v1/auth ยืนยันสิทธิ์เข้าใช้งานด้วย License หรือ Username/Password
Headers: X-Session-Token: <token> • X-Signature: <rsa_sig>
Payload (License): {"action": "license_only", "license_key": "KAWAII-XXXX", "hwid": "hash"}
3. POST /api/v1/var ดึงค่าตัวแปรเซิร์ฟเวอร์ (Server Variables) ที่ถูกเข้ารหัส
Payload: {"session_token": "...", "var_key": "APP_SECRET_TOKEN"}

Troubleshooting & Common Status Codes

429 Too Many Requests Rate Limit Exceeded

เซิร์ฟเวอร์มีระบบ Rate Limiter อัจฉริยะแบบ Sliding-Window เพื่อป้องกันการเดาคีย์และการโจมตี DDoS หากยิงเกินโควต้า เซิร์ฟเวอร์จะคืน Header Retry-After: <seconds> ให้รอจนกว่าเวลาจะหมด

HWID Mismatch Hardware ID Locked

คีย์ถูกผูกกับเครื่องคอมพิวเตอร์อื่นไปแล้ว หากผู้ใช้เปลี่ยนอุปกรณ์ สามารถกดปุ่ม Reset HWID ได้ในหน้า Dashboard แท็บ Registered Users

Version Mismatch Update Required

ตัวไคลเอนต์ใช้เวอร์ชันต่ำกว่าที่เซิร์ฟเวอร์กำหนดใน App Settings ฟังก์ชัน GetDownloadUrl() จะส่งลิงก์ตัวอัปเดตไปให้โปรแกรมเปิดดาวน์โหลดโดยอัตโนมัติ
